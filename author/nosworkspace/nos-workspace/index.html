NOS Workspace

Hoyeon Yeo / NOS Workspace

I made NOS Workspace to keep documents and HTML pages in one place.

Fixing and sharing a report

Sign in, paste an HTML report into NOS, and click text in the preview to fix the wording. Then save the report and create a share link. The person who receives the link can open the report without a NOS account.

If you later fix a heading and save again, anyone who reopens the link you already sent sees the updated report.

How I used Claude

I used Claude Code for implementation, debugging, testing and documentation.
